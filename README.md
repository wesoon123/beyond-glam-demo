# Beyond Glam Demo

Responsive single-page website demo for Beyond Glam Hair & Beauty Studio.

## Included

- Responsive navigation
- Hero section and calls to action
- Services section
- About section
- Gallery
- Client reviews
- Appointment request form
- Contact details and Google Maps link

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

> Demo note: the gallery currently uses Unsplash placeholder photography. Replace these images with approved Beyond Glam assets before production use.
